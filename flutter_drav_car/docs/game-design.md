# 小小司机游戏设计与开发文档

版本 1.0 · 2026年11月24日 · 平台 Android · 实现 Flutter

## 产品目标

为约4岁儿童提供一款由家长陪同体验的轻松驾驶游戏。孩子双手竖握手机，像方向盘一样向左或向右倾斜，让自动向前的小车躲开路障、收集金币。无需识字、踩油门或理解复杂规则。

第一版交付可离线运行的安卓体验 APK、Flutter 源码及验收说明。不使用广告、购买、账号、网络服务或数据采集。

## 游戏流程

首页选择草地、海边或糖果场景，点击橙色开始按钮，进入驾驶准备。用图示说明左右转动手机；保持舒服的握持姿势点击出发，记录中立方向。倒计时结束后自动前进。

每局90秒。金币和软质路障从远处向下移动；靠近金币自动拾取。障碍只减速并触发保护泡泡，不扣金币，不出现失败或惊吓画面。结束时显示金币、星星与鼓励文案，可以再玩一次或返回首页。每完成一局提示休息眼睛。

## 操作和适龄设计

- 固定竖屏，手机上端朝上，稍向后倾斜。利用重力加速度计算左右滚转角，相对出发时的角度控制横向目标位置。
- 左右约25度即可到达道路两侧；加入死区和低通滤波，过滤小幅手抖；角度差跨越正负180度时正确归一化。
- 随时暂停、重新校准或切换触控；传感器不可用时自动提供触控提示。底部左右按钮支持按住移动，也支持在道路上拖动。
- 所有主要按钮至少56逻辑像素，文字配图标；默认舒缓速度，可切换轻快速度。
- 进入后台或收到系统中断时自动暂停，返回后由玩家主动继续；暂停期间计时、障碍和音乐均停止。

## 关卡与数值

| 项目 | 规则 |
| --- | --- |
| 单局时长 | 90秒有效驾驶时间，不计暂停和准备 |
| 赛道 | 连续横向移动，三条生成轨道 |
| 金币 | 每枚加1，无连击压力 |
| 舒缓速度 | 物体纵向速度约0.24个屏幕高度每秒 |
| 轻快速度 | 约0.32个屏幕高度每秒 |
| 出生节奏 | 每约1.5秒一组，初始安全教学金币 |
| 路障 | 一组最多占据一条轨道，保证留有通道 |
| 碰撞 | 缩小碰撞盒；减速0.8秒；保护2.4秒，避免连续碰撞 |
| 星星 | 完成即1星；收集12金币2星，24金币3星 |

障碍与金币位置不重叠；随机种子可注入测试。速度不随时间无限增加。即使不移动，小车也能完成本局。

## 视觉与声音

采用奶油白、薄荷绿和暖橙色的绘本风格。以 Flutter Canvas 绘制带圆角的小车、树木、海浪、软质路障、道路和金币；所有图形随屏幕缩放，不依赖外部图片。

金币有旋转、亮光、粒子和加分反馈；碰撞产生柔和尘团、车身短暂晃动和半透明保护泡泡；结算有彩纸与星星。避免频闪和剧烈屏幕震动。

使用程序合成并随包携带的原创 WAV：金币清脆双音、碰撞柔和低音、开始提示、完成上行和弦；轻柔循环背景旋律。背景音乐和音效独立开关，并在本机保存。暂停和后台停止音乐，退出释放播放器。声音播放失败不影响驾驶。

## 页面

首页包含品牌、插画赛道、场景选择、开始按钮和设置入口。准备层说明转动手机并允许触控模式。游戏 HUD 显示金币、剩余时间、暂停及声音按钮；底部显示方向盘反馈和左右触控按钮。暂停层提供继续、校准和返回。结算显示本局金币、最佳记录、星星及重玩。

设置包含音乐、音效、舒缓或轻快速度、倾斜或触控模式。最佳金币、场景与设置写入 Android SharedPreferences，仅保存在设备本地。

## 技术方案

Flutter StatefulWidget 负责页面与交互，CustomPainter 负责绘制。独立 Dart GameModel 负责倒计时、生成、移动、碰撞、粒子及奖励，Ticker 驱动并限制单帧步长，避免切后台后的跳帧。

Android Kotlin 通过 EventChannel 传递 SensorManager 加速度数据；MethodChannel 提供 SoundPool 短音效、MediaPlayer 循环音乐、SharedPreferences 设置。传感器仅在游戏准备或游玩时注册，暂停或后台注销。不依赖第三方游戏或音频插件。

包名 com.littlewheel.little_driver；minSdk沿用Flutter支持的Android基线。体验包采用本机调试签名的release构建，不作为商店正式发布签名。

## 验收与交付

自动验证：静态分析无错误；模型测试覆盖左右边界、金币拾取、碰撞保护、暂停计时、90秒结束和生成通道；页面测试验证首页及开始流程。构建后检查APK包名、版本、权限和签名。

运行验证：在可用安卓设备或模拟器检查首页、准备、驾驶、暂停、设置、结算与重玩，保存截图。重力手感、扬声器音量和低端机性能需要实际手机体验确认，交付说明需明确实际验证范围。

交付路径：docs/game-design.md、README.md、完整Flutter工程、dist/little-driver-android.apk。安装后竖握手机，在准备页校准，轻轻左右倾斜即可体验。

## iPhone真机体验补充

应体验要求增加iOS平台，采用CoreMotion与AVAudioPlayer原生桥接，兼容同一套游戏逻辑。自动签名团队为用户指定的上海诚助 D76FYB6A7W。已通过ios-deploy成功安装到iPhone 8 Plus iOS 16.7.12；该旧版设备使用兼容工具连接，Xcode CoreDevice列表不提供正常安装目标。倾斜数据统一为Android重力加速度坐标，避免两平台左右方向相反。iPhone启用静音开关时背景声可能静音。

技术参考：[Apple CoreMotion加速度采集](https://developer.apple.com/documentation/coremotion/getting-raw-accelerometer-events)。

## 版本1点1 摇摇车驾驶与道具

驾驶画面升级为Canvas实时绘制的2点5D透视场景，加入天空、云朵、远山、弯曲道路、近大远小的树木、立体金币和光泽玩具车。道路、物体、粒子和车身共用投影，碰撞在同一逻辑接触平面判断。底部是玩具仪表台，方向盘可按喇叭；默认柔和车身摇摆，可在设置关闭。手机不会产生机械摇动。

普通道具拾取后存入顶部按钮，每类最多存3个。点按钮才消耗：泡泡盾保护8秒；小磁铁8秒内吸引附近各车道金币；彩虹星6秒内金币双倍，保持原车速。效果期间重复点击不会浪费库存，暂停冻结效果时间。开局先在中间车道提供泡泡盾教学。

新增四种自动变身道具：小飞机、玩具坦克、小恐龙、小猪佩奇。碰到对应图案盒子立即变身10秒，显示相应的立体玩具造型；飞机有浮动和机翼，坦克有滚动履带，恐龙有尾巴和背刺，佩奇显示粉红猪头与红裙。变身期间路障被冲碎，产生带旋转和重力轨迹的橙白碎块及柔和破裂音，不减速。变身结束恢复小车并提供1点2秒保护。

变身期间禁止生成任何变身道具；激活时清除路上已生成的变身盒子，防止接力和覆盖。暂停不消耗变身时间，重玩会清空变身和库存。四种变身盒子按轮换顺序投放，每6行最多1个，与普通道具共享安全奖励车道。

背景音乐支持小星星、两只老虎及原创欢乐兜风。前两首使用传统旋律，由项目脚本重新编排并合成轻柔器乐录音，不含歌词、不下载商业录音。设置和暂停页可以换歌，音乐和音效独立开关。参考旋律：[小星星主题](https://www.mutopiaproject.org/cgibin/piece-info.cgi?id=2236)、[Frère Jacques教学乐谱](https://education.nsw.gov.au/content/dam/main-education/teaching-and-learning/curriculum/key-learning-areas/creative-arts/media/documents/creative-arts-s4-music-kasca-sequences-music-handouts-piece-9-frere-jacques.pdf)。

## 版本1点1点1倾斜驾驶

按最新操作要求移除所有手指转向：底部左右按钮、道路拖动、准备页和暂停页切换触控、设置中的手指操作。历史触控设置被忽略，方向盘居中保留喇叭操作，道具依旧点击使用。传感器失败会暂停并提供重试，无法读取方向时不会继续倒计时或驾驶。
