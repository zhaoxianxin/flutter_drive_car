# 声音来源

所有WAV文件均由 tools/generate_audio.py 用数学波形合成，未复制第三方录音或人声。

- twinkle.wav：传统旋律 Ah vous dirai-je maman，即小星星旋律；本项目自行编排的音乐盒器乐版。
- frere.wav：传统旋律 Frère Jacques，即两只老虎旋律；本项目自行编排的音乐盒器乐版。
- music.wav：本项目原创背景旋律。
- 其余WAV：原创金币、拾取、开启道具、喇叭、变身、碎裂、开始、完成音效。

旋律参考：
